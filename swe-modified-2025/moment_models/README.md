# Moment-Model Data Generators

Created: 2026-08-26
Repository-relative folder: `swe-modified-2025/moment_models/`

This tree contains the active numerical kernels and command-line drivers for generating moment-model data for Examples 4.1--4.3.
NumPy is the only Python package dependency.

Plotting, OpenFOAM comparison, exported tables, analysis, and existing results are excluded.
Generated `data/` and `Data/` folders are ignored by the package.

Status on 2026-08-26: source generators are prepared and syntax-checked; the production parameter matrix was not rerun during packaging.
